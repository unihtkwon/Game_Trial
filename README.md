# 🎰 Bingo Game — Series Edition

두 플레이어가 번갈아 숫자를 뽑아 **먼저 5승을 달성**하는 빙고 시리즈 게임입니다.
서버 없이 브라우저에서 바로 실행됩니다.

---

## 실행 방법

`index.html` 파일을 브라우저에서 직접 열거나, 로컬 서버로 실행합니다.

```bash
# Windows
start index.html

# 또는 Python 로컬 서버
python -m http.server 8080
# → http://localhost:8080 접속
```

---

## 게임 규칙

### 기본 규칙
| 항목 | 내용 |
|------|------|
| 플레이어 | 2명 (Player 1 vs Player 2) |
| 빙고판 | 3×3, 숫자 1~9 랜덤 배치 |
| 진행 | 번갈아 가며 **SPIN** 버튼을 눌러 숫자 추첨 |
| 마킹 | 뽑힌 숫자는 **양쪽 보드에 동시에** 표시 |
| 승리 조건 | 가로 · 세로 · 대각선 중 한 줄 완성 |
| 무승부 | 같은 스핀에 두 플레이어 동시 완성 |

### 시리즈 규칙
| 항목 | 내용 |
|------|------|
| 최대 게임 수 | **9게임** |
| 시리즈 우승 조건 | **5승** 먼저 달성 |
| 무승부 처리 | 양쪽 모두 **+1승** (동시 빙고) |
| 조기 종료 | 5승 달성 시 남은 게임 없이 즉시 종료 |
| 9게임 후 동점 | 시리즈 타이 |

## 게임 진행 흐름

```
시리즈 시작
    │
    ▼
[게임 시작] 양쪽 3×3 보드 랜덤 생성
    │
    ▼
현재 플레이어가 SPIN 클릭
    │
    ▼
슬롯머신 애니메이션 → 숫자 공개
    │
    ▼
양쪽 보드에 숫자 마킹
    │
    ├─ 빙고? ──────────────────────────────┐
    │                                      │
    │  NO → 턴 전환 → 다음 플레이어 스핀    │  YES
    │                                      ▼
    │                              시리즈 승점 업데이트
    │                              스코어보드 슬롯 기록
    │                                      │
    │                        ┌─────────────┴──────────────┐
    │                        │ 5승 달성 or 9게임 완료?    │
    │                        │                            │
    │                     YES (시리즈 종료)           NO (계속)
    │                        │                            │
    │                 시리즈 결과 모달             게임 결과 모달
    │                 (최종 점수 + 기록)           (스코어 표시)
    │                 [New Series]               [Next Game →]
    │
    └──────────────────────────────────────────────────────
```
